\section{Limitations and Disclosures}
\label{sec:limitations}

In accordance with our preregistered auditing protocol, we explicitly disclose the scope boundaries, architectural assumptions, and methodological limits of this work:

\begin{itemize}
    \item \textbf{D1$'$ (Provided Collective Variables):} Model input is restricted to predefined 2D backbone dihedrals $(\phi, \psi)$. This benchmark evaluates the model's capacity to represent multistable energy landscapes and relative free energies, not unsupervised collective variable discovery.
    \item \textbf{D2$'$ (Absence of Analytical Prior $V_{\text{base}}$ on Molecular Data):} While the synthetic double-well system leverages a hybrid potential $V_{\text{total}} = V_{\text{base}} + v_{\text{net}}$, no analytical prior exists for Alanine Dipeptide. The learned potential $V_\theta$ is parameterized purely by $v_{\text{net}}$, rendering the prior layer only partially applicable.
    \item \textbf{D3$'$ (EDA 1D Barrier Proxy Scope):} The 1D $\phi$ density barrier proxy derived in our Phase 1 EDA measures intra-branch density fluctuations rather than the 2D minimum free-energy path saddle point. Consequently, quantitative barrier claims are avoided, and only relative macrostate depth ordering (R3) is evaluated.
    \item \textbf{D4$'$ (Single Molecular System Boundary):} Empirical validation is performed exclusively on Alanine Dipeptide ($750{,}000$ frames). We make no claims regarding generalization to higher-dimensional protein dynamics or multi-protein datasets.
    \item \textbf{D5$'$ (Full Disclosure of Exploratory $\alpha_L$ State & Artifacts):} All exploratory R5 results are reported in full. The model recovers the physical $\alpha_L$ state ($(+\text{53}^\circ, +\text{31}^\circ)$, $3.0\%$ data population) across 5/5 seeds, alongside a second high-$V$ attractor near $(+\text{58}^\circ, +\text{175}^\circ)$ disclosed as a shallow numerical artifact.
    \item \textbf{D6$'$ (Auditor Implementation Error \#5 Disclosure):} In Phase 2 baseline evaluation, the initial Monotone DEQ implementation scaled its update by $0.9\pi \approx 2.83$, violating the contractive theorem premise ($\text{Lip} \le 1.91$). This error was logged in the audit ledger (Error \#5) and corrected in Version 2 ($g(q) = (1-\lambda)q + \lambda \cdot 0.9 \cdot \tanh(\cdot)$, $\text{Lip} \le 0.788 < 1$), which produced the verified $N=1$ Banach collapse.
    \item \textbf{D7$'$ (Audit Incident Log Summary):} All forensic audit incidents (INC-01 through INC-21) and sealed script hash manifests are preserved in the git repository history for cryptographic reproducibility.
\end{itemize}
