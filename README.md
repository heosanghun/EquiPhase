# EquiPhase: 조건부 상분리 단백질을 위한 열역학 정합형 심플렉틱 DEQ 및 검증 프레임워크

**EquiPhase**는 환경 변화(염분 농도)와 학습 시 보지 못한 새로운 단백질 서열에 대해, 단백질의 **조건부 액체-액체 상분리(LLPS)** 현상을 얼마나 잘 예측하는지 정밀하게 평가하기 위해 설계된 인공지능 벤치마킹(성능 평가) 시스템입니다.

> 💡 **쉬운 용어 설명:**
> * **액체-액체 상분리(LLPS):** 물속에서 기름방울들이 뭉쳐서 분리되듯, 세포 안에서 특정 단백질들이 뭉쳐서 방울처럼 분리되는 생물학적 현상입니다. 치매 등 질병과 밀접한 연관이 있습니다.
> * **본질적 무질서 단백질(IDPs):** 딱딱하게 고정된 3차원 구조가 없고, 실처럼 유연하게 흐느적거리며 움직이는 단백질입니다. 상분리 현상을 주도합니다.
> * **분포 외 데이터(OOD, Out-of-Distribution):** 인공지능이 학습할 때 보지 못했던 완전히 새로운 염도 환경이나 단백질 서열을 의미합니다.

## ✨ 신규 업데이트: 열역학 정합형 심플렉틱 DEQ (S-DEQ) 및 UPAF 구현

기존의 일반적인 인공지능 예측 모델들이 고정된 단백질의 사진(정지된 단편 구조)만 찍어내던 한계를 극복하고, 단백질이 주변 환경에 따라 움직이는 **에너지 변화 지도(동역학)**를 물리 법칙에 맞게 학습할 수 있도록 모델을 업그레이드하였습니다.

### 1. 기존 심층 평형 모델(DEQ)의 한계: '수축 붕괴' 문제 해결
* **기존 문제점:** 일반적인 심층 평형 모델(DEQ)은 연산 과정에서 수렴성(결과가 하나의 값으로 좁혀지는 성질)을 확보하기 위해 전역 수축 조건(Lipschitz 상수 $L < 1.0$)을 만족해야 합니다. 그러나 실제 단백질 데이터를 적용하자 수축 계수가 $L_{max} \approx 6.4$로 치솟으며 **수축 조건이 무너지는 현상(Contractivity Collapse)**이 발견되었습니다. 이로 인해 인공지능이 다중 안정 상태(단백질이 가질 수 있는 여러 개의 안정된 구조)를 표현하지 못하고 단 하나의 상태로만 찌그러지는 치명적인 문제가 있었습니다.
* **해결책 (Symplectic DEQ):** 에너지와 위상 공간의 부피를 보존하는 물리 법칙인 **해밀토니안 심플렉틱 동역학(Symplectic Dynamics)**을 신경망에 이식하였습니다. 마치 개구리가 뜀박질하듯 위치와 운동량을 번갈아 계산해 오차를 누적하지 않는 **리프프로그 통합법(Leapfrog Integrator)** 물리 엔진을 구현하여, 강제 수축 없이도 단백질이 가질 수 있는 여러 안정된 에너지 우물들을 자연스럽게 모델 내에 공존시키는 데 성공하였습니다.

### 2. 수치 계산 물리 검증 완료 (`verify_mathematics.py`)
구현된 물리 엔진이 실제로 물리 법칙을 따르는지 수학적으로 완벽히 검증하였습니다:
* **부피 보존성 (리우빌 정리):** 마찰이 없을 때 야코비안 행렬식(위상 공간의 부피 변화율)이 정확히 **`1.0000000`**으로 유지되어 정보나 부피의 손실이 없음을 증명하였습니다.
* **물리적 마찰 감쇄:** 마찰력(damping = 0.2)을 주었을 때의 에너지 소실률이 이론적 한계값인 **`0.4096000`**에 정확하게 수렴함을 확인하였습니다.
* **Krylov 고유값 분석:** 복잡한 회전 성분을 가진 고유값의 스펙트럼 반지름을 2단계 Krylov 투영법으로 정확하게 계산(`0.7997` vs 실제 `0.8000`)해 내었습니다.
* **이중 우물 포텐셜 추적:** 1차원 이중 우물 물리 다리 테스트를 통해, 단백질이 가질 수 있는 **2개의 안정한 상태($z^* = \pm 1.0$, 마진 $0.10$)**와 그 사이의 **1개의 불안정한 장벽 상태($z^* = 0.0$, 마진 $-0.05$)**를 정확히 포착하였습니다.

### 3. UPAF를 통한 지름길 학습(Shortcut Learning) 차단
* 인공지능이 단백질의 물리적 규칙을 배우지 않고, 서열의 길이나 단순히 특정 문자열 패턴만 외워서 편법으로 정답을 맞추는 꼼수(지름길 학습)를 방지하기 위해 **UPAF 플레이스보 감사 축**을 적용하였습니다. 백혈구(WBC) 이미지 데이터를 활용한 시뮬레이션에서 데이터 누수가 감지되었을 때 즉각 경보(`LEAKAGE-DETECTED`)를 울려 꼼수 차단 능력을 검증하였습니다.

## 📌 핵심 과학적 발견 및 최종 결론 (Findings & Verdicts)

본 프로젝트는 사전에 등록된 엄격한 가설 검정 프로토콜에 따라 두 가지 핵심 트랙을 평가하였고, 다음과 같은 결론을 도출하였습니다:

### 1. 가설 H1: 소금 농도 변화(염도 Extrapolation)에 대한 DEQ의 효과 (Phase 3)
* **가설:** 수학적 고정점을 찾는 심층 평형 모델(DEQ)이 학습 환경(염도 $\le 150$ mM)에서 보지 못한 극한 환경(염도 $> 300$ mM)에서의 상분리 여부를 더 잘 예측할 것이다.
* **최종 판정:** **가설 기각 (효과 없음 / NULL).**
* **결과:** 예상과 달리 DEQ 모델은 다른 기본 모델들보다 낮은 성능을 보였습니다. (검증 성능 AUPRC 0.6570, 최종 시험 성능 AUPRC 0.6078). 오히려 반복 횟수를 고정하여 풀어헤친 단순 재귀 모델(Ablation A: $K=8$, 시험 성능 0.6503)이 더 우수했습니다.
* **원인 분석:** **수축성 붕괴(Contractivity Collapse).** 립시츠 제약이나 감쇄 장치를 넣었음에도 야코비안 포텐셜 수축 계수가 $L_{max} \approx 6.4 \gg 1.0$로 유지되어 수렴 조건이 무너졌고, 역전파 과정에서 신호가 왜곡되어 노이즈가 낀 그래디언트가 전달되었기 때문입니다.

### 2. 가설 H2: 새로운 단백질 가문에 대한 일반화 능력 (Phase 5)
* **가설:** 단백질 인공지능 임베딩(ESM-2) + 물리화학적 특성 정보 + 단조성 제약(농도가 높아지면 상분리도 항상 더 잘 일어난다는 물리적 상식 제약)을 결합하면, 한 번도 보지 못한 새로운 단백질 가문(Sequence Family)에 대해서도 훌륭히 예측할 것이다.
* **최종 판정:** **가설 기각 (효과 없음 / NULL).**
* **결과:**
  * **AttentionMLP (사전 등록된 최고 모델):** 검증 데이터에서는 기준치(0.6812)를 상회하는 성능(**0.7883**)을 보였으나, 최종 보안 평가 데이터(Locked Test Set)에서는 가문 수의 통계적 한계로 인해 기준 성능(0.6448)을 확실하게 넘어섰음을 입증하지 못했습니다 (성능 **0.7697**, 95% 신뢰구간 하한선 0.6264가 기준보다 낮음).
  * **단조성 제약 XGBoost (사후 탐색 모델):** 공식 검정에는 실패했으나 사후 테스트 결과 최상위 성능(성능 **0.8313**)을 보여주어 미래의 유망한 접근법으로 기록되었습니다.
* **핵심 교훈:**
  * **라벨 노이즈 병목 현상:** 조사 결과 저농도 상분리 데이터베이스 레코드의 **45.71%**가 동일한 서열임에도 실험 환경에 따라 상반된 라벨을 갖고 있어 예측 성능의 천장을 가로막고 있었습니다.
  * **단조성 제약의 유망성:** 농도 증가에 따른 예측치의 항상성 제약은 이 라벨 노이즈를 극복하는 중요한 열쇠이며, 향후 신규 데이터셋을 통해 공식 검증을 진행할 예정입니다.

## 🛡️ 과학적 연구 규정 및 무결성 (Scientific Rigor)

본 프로젝트는 머신러닝 연구에서 흔히 일어나는 데이터 오염, 꼼수 학습 및 결과 부풀리기(p-hacking)를 완전히 차단하기 위해 다음의 3대 규정을 시스템 수준에서 강제 적용합니다:
1. **규정 R1 (사전 등록 계획 고정):** 예측 타겟과 설정값은 JSON 파일로 사전 동결되며, 부득이한 사정으로 변경 사항이 발생할 시 상세 사유와 시각을 `DEVIATIONS.md` 파일에 기록하여 사후 조작을 방지합니다.
2. **규정 R2 (통계적 신뢰 한계 검증):** 모든 최종 성능 보고치는 단순히 평균값만 표기하는 것을 금지하며, 가문별 상관관계를 고려한 **1,000회 반복 블록 부트스트랩 분석**을 거친 95% 신뢰구간 하한선을 기준으로 통과 여부를 엄밀히 판정합니다.
3. **규정 R3 (결과 재활용 및 위조 원천 차단):** 평가 하네스(Harness) 연산 도중, 성능 수치나 손실값의 중복 복제 혹은 사후 복사-붙여넣기 꼼수 감지 시 즉각 연산을 강제 중지하고 예외(`RecyclingFabricationException`)를 터트려 조작 시도를 격리합니다.
